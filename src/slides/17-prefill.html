The asymmetry The Mac is 2.2× behind on writing — and 11.6× behind on reading.

Prefill is arithmetic; decode is memory traffic. The 5090 has roughly three times the Mac's bandwidth but around five times its peak matrix compute — so which phase you are in decides how big the gap feels. The measured prefill gap is wider still, because llama.cpp's CUDA path is mature and its Metal path does not yet use the matrix units built into the M5 GPU (Apple calls them Neural Accelerators; they are not the separate Neural Engine, which no local runtime uses). Every rate here is an order‑of‑magnitude estimate for one 8 B model at 4‑bit, not a benchmark of your machine — only the clock is real. Attention is also quadratic, so a really long prompt is worse than this straight line suggests.
