04 — Your turn

Same 15 GB. Same tokens per second. Which one do you download?

Bigger and more compressed usually wins. All three read 15 GB out of memory for every token, so all three decode at the same speed. Bandwidth ÷ size does not care how the bytes are arranged. Size and speed are held constant, which leaves exactly one variable: how much model you got for the money.
