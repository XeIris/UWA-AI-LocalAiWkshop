03 — The one formula

Decode speed is a memory problem

tokens/sec ≈ memory bandwidthGB / SEC active model sizeGB

The through-line of this entire workshop

Prefill
Reading your prompt
Every token of the prompt is processed at once. The chip is doing arithmetic flat out.
Limited by compute — FLOPS
Feels like: the pause before the first word
Decode
Writing the answer
One token at a time, and every active weight must be read from memory for each one.
Limited by memory bandwidth — GB/s
Feels like: the speed the words appear

A Mac has modest compute but wide memory, so it writes quickly and thinks slowly. A big discrete GPU is fast at both, right up until the model stops fitting in its VRAM. Everything you run tonight is dense — every weight is active for every token, so active size is simply file size. Section 06 has the models where those two part company.
