02 — Under the hood

If you outgrow LM Studio

Ollama

Terminal-first. One command pulls and runs a model, and it serves an API other apps can talk to.

OLLAMA RUN QWEN3

Open WebUI

A browser front end you self-host, usually pointed at Ollama. Multi-user, and closest to the hosted chat apps.

RUNS IN A BROWSER

Unsloth

Runs your models like the others — and is also the tool people use to train one on their own data.

RUNS AND TRAINS

Same GGUF files underneath, so the model you just downloaded is not wasted — but moving is not quite free. Open WebUI is a front end and needs Ollama (or another server) behind it, and Ollama imports a local GGUF through a Modelfile rather than opening it directly. Unsloth finds what you already have, but installs a Python toolchain to do it, and its interface is still labelled beta.
