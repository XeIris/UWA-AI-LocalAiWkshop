Why bother Smaller file → fits in memory you actually have. Half the bytes is twice the tokens per second — same formula as §3.

Note the shared scale. A quant does not store 24 tiny numbers — it stores 24 tiny integers plus one full-precision multiplier for the block. That multiplier is why a “4‑bit” file is never exactly 4 bits per weight. One scale over 24 weights costs this block 4.67 bits each; a real Q4_K_M block is larger, carries more metadata, and lands at 4.83 — which is why the 30B on the next slide is 18.1 GB and not the 17.5 above.
