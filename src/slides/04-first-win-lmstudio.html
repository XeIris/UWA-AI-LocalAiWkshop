Take plain LM Studio, not LM Studio Bionic. Bionic is a second, separate app from the same team — a coding and document agent that runs on top of a model, and it can point at open models in the cloud as well as local ones, so it is not automatically offline the way this app is. It is not a newer version of this one; the two are meant to be installed side by side. Tonight we want the app that downloads and runs the model.
