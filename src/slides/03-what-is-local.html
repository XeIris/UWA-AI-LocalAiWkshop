00 — What is a local LLM?

A file of numbers, and a program that reads it

A language model whose inference — the arithmetic that produces each word — runs on hardware you own. In practice that means an open-weight model, because someone has to publish the file before you can hold it. It is the same kind of model as the one in the browser tab. What changes is the address.

01

The weights

One file you download once. A few billion numbers, learned during training and then frozen. Nothing about it changes as you use it.

GEMMA-3-1B-IT-Q4_0.GGUF · 720 MB
02

The runner

An ordinary desktop app that loads that file into memory and does the multiplication. LM Studio tonight; the engine underneath is llama.cpp.

INSTALLS LIKE ANY OTHER APP
03

Your memory

The file has to fit in RAM or VRAM, and is read end to end for every word it writes. That is why the next two hours are mostly about memory.

CAPACITY → FITS · BANDWIDTH → SPEED
Cloud your text→ the internet→ someone’s datacentre→ an answer
Local your text→ your RAM→ an answer

Open weights are not the same as open source. You get the finished numbers to keep, run and fine-tune. The training data and the code that made them usually stay private, and a license can still restrict what you do with the output. Read the model card.
