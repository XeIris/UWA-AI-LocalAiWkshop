This is why a million tokens is a hardware problem, not a setting. Drag to the far right: at every size on this slider the cache dwarfs the weights it belongs to, and past a couple of billion parameters it runs beyond 100 GB. Set the machine to your own and watch what happens to the bar. Frontier providers cope with paged caches, KV quantization, sliding windows and racks of accelerators; on your laptop the honest move is to set the context you actually need, and LM Studio hands you that slider. Quantization is the one lever that does not help here: dropping the weights to 4‑bit quarters the file and leaves the cache untouched — that is what the separate cache control is for. The per‑token figure is an estimate, read off released models of each size; two models the same size can differ by half again.
